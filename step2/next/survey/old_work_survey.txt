VERDICT 1. Would a (Q^GF)^2 = 0 gauge fixing from these projects remove the composite-line layer?
------------------------------------------------------------------------------------------
Partly. It removes the composite-line layer along Delta, P, M and R, and theta with it. Along Q, S and K
the layer stays: the same graphs come back as ordinary bivalent vertices.

Mechanism used by projects 1, 3 and 4:
  - non-minimal pair (cbar, b), gauge fermion Psi = -+ int cbar (d.A + (xi/2) b);
  - antifields shifted by dPsi/dPhi;
  - b eliminated, which leaves +1/2 (cbar^dd - d.A)^2 / xi in S_0, a term quadratic in antifields.
  - Q^GF then maps antifield slots to field slots only (on coordinates: every nonzero row reads an
    antifield). Hence (Q^GF)^2 = 0 trivially, Im Q^GF = the field Lagrangian, and [Q,Q^GF] = -d^2 on every
    slot at xi = 1.
  - Machine checks: project 1 check_qgf.py / qgf_checks.json (30/30); project 3 sqed/design/check_free.log
    (Q^2 = 0, (Q^GF)^2 = 0, [Q,Q^GF] = H on all coordinates, Schwinger-Dyson inverse); project 4
    tex/qed_costello_one_loop.tex (40 coordinates).

Consequence in the current project's own formulas:
  - The composite kernel is 2 P* X P* with P* = Q^GF G, G = int_eps^T e^{-tH} dt.
  - Its part along Delta is v.(P*)^2 + (P*)^2 v. (prop:c9-composite (i)), and (P*)^2 = (Q^GF)^2 G^2 = 0.
  - So the composite A_V-c line along Delta vanishes, and theta (fixed to -1/3 by the arity-two equations)
    disappears from D_1, and likewise from P_1, M_1, R_1. Psi is Poincare-, scale- and R-invariant if cbar
    has weight 2.
  - For a generator X, with (Q^GF)^2 = 0 and Ker Q^GF = Im Q^GF (p != 0):
        P* X P* = Q^GF G X Q^GF G,
    which vanishes iff X preserves the gauge-fixing Lagrangian. For X = Q, S, K it does not (Psi is not
    supersymmetric or conformal).
  - In the gauge-fixed frame these terms are s_X Psi:
      - (s_alpha V) d cbar, a lambda-cbar line along Q and S;
      - 4 k.V cbar, a V-cbar line along K;
      - the arity-two vertex -1/2 cbar T cbar (alpha alphabar), without which the master equation fails.
    The last is a negative control in project 3 check_master.log; it was missing at first and added later
    in project 2.
  - The layer is therefore moved, not removed, along Q, S, K. No surveyed project has a gauge fixing that is
    invariant under SUSY or K, and none exists for off-shell N=4.
  - Costello's first-order formulation [C07] also gives (Q^GF)^2 = 0, but it was not used in any old
    project for untwisted N=4 and has the same X-non-invariance.

Cost of switching:
  - new letters cbar and cbar^dd, and the propagator c-cbar replaces c-A^*;
  - all Step-1 data must be redone: I^CT, the log class Y, 27/16, Ob_3, F_3.
Gain:
  - Costello's axioms (3) and (5) hold, so [C07 Lemma 6.5.1, 6.6.2] apply directly;
  - theta disappears along Delta, P, M, R.
Nothing is gained for Q_1, S_1, K_1.
