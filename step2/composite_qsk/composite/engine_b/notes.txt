1. OBJECT COMPUTED
Z_x(X_a,X_b;eps) is taken as the Q-image part of the composite cycles (master identity, Prop prop:cc-master):
   Z_x = (hbar/2) d_{K_x}( chain trees with one edge K_eps - K_0 ),
because in the manuscript Delta_0 = -d_{K_0} (Def c1-bracket, Def c3-delta), so the bracket vertex {I,M}_eps - {I,M}
is MINUS the tree with an edge K_eps - K_0 and Q d_{K_x} = -d_{K_x} Q (Lemma lem:cc-kernels (v)).  This is the
"minus (hbar/2) d_{K_x} of the chains with the special edge" of Def def:cc-sp when the special edge is read as the
bracket vertex (Prop c4-defect1 wording); with the special edge read as the plain edge K_eps - K_0 the definition
would carry the opposite sign.  The sign was not calibrated: GC3 (-1/3, -8/3) is a first-principles result.
STr form: (hbar/2) d_K closes a tree with weight (hbar/4) STr per edge position (from W_1 = (hbar/2) sum (1/n) STr[(P Pi H)^n]
and d/dt W_1(P + t dP) = hbar d_{dP} W_0; checked on the toy quadratic model), hence
   Z_x(X_a,X_b) = (hbar/4) sum_{vertex sequences} sum_{c != sigma} s(c,sigma) STr[E_0 Pi h_1 E_1 ... E_k Pi H_M],
E_c = K_x, E_sigma = (e^{-eps k^2}-1) k0, others P(eps,oo); s(c,sigma) = (-1)^{n(<sigma) + [c<sigma] + n(<c)}, n(<j) the
number of odd outputs at the vertices before edge j: coefficient of delta_sigma delta_c (both kernels odd) in front.
C^(2)_x = coefficient of eps^0; poles z_m = coefficients of eps^{-m}.  Units hbar/(16 pi^2) times the colour words
C_w = (1 (x) ad_{Y_w1}...ad_{Y_wr})(-,-)^{-1} (X_a on the first factor), as in the twoletter engine.

3. COMPOSITE LINE IN KERNEL FORM (route B; engine A uses the vertex form)
  K_{P_b} = (d_b(x)1 - 1(x)d_b) X = 2 i (b.k) MX(k) e^{-2 eps k^2}/k^4, two Schwinger segments t', t'' >= eps.
  K_Delta = (v.(x)1 - 1(x)v.) X = [2 i k_mu (x + y)^mu + 2(w_row - w_col)] MX e^{-2eps k^2}/k^4,
x, y the positions of the vertices at the row and column ends.  Canonical form (Def def:cc-canonical): position part
from x, y -> x_O: (C_Delta)^b = 2 C_{P_b} identically (GC4 structural); translation-invariant part from (x - x_O), (y - x_O):
  option 3 (default): x + y - 2x_O = (x - y) + 2(y - x_O); (x - y)^mu acting on the line is i d/dk_mu, giving the Euler
           operator -2(4 + k.d_k)[MX e^{-2eps k^2}/k^4] = (-2 + 8 eps |k|^2) X: a constant -2 X and 8 eps MX e^{-2 eps k^2}/k^2,
           whose eps^0 part is 8 x [eps^{-1} coefficient] of the graph with the line as ONE segment t >= 2 eps;
           (y - x_O)^mu = -i d/dh_mu of a momentum h injected at the column-end vertex and absorbed by omega;
  option 2 (check): injections at both ends (x - x_O) + (y - x_O).
Options 2 and 3 agree (Lemma lem:cc-kernels (ii); GC4b) on the bilinear and on twist two.
Letter at an end of the line: when that end is the vertex M, the position factor sits at the letter, and the letter's
derivatives act on it (d^alpha_x [x^mu (d_mu X)(x-y)]); implemented by letting the injected h enter that letter's
derivative factor only (injM).  Without this the canonical-form identity [C^0, d_b] = C^b failed on the k = 1 kernels
(A_n, Z) -> Z and twist two failed at S' = 3; with it the identity holds on every kernel (GC4c).

4. EXACT INTEGRALS (ce_int.py; route B representation)
After the Gaussian loop integral (centre = sum alpha_p cur_p, Phi = sum alpha_p |cur_p|^2 - |centre|^2,
num_j = (Lap^j Num)(centre)/(j! 4^j), the special-edge factor -|k_sigma|^2 in Num):
  [eps^{-m}] = (16 pi^2)^{-1} int_0^1 dv int_{u_f >= c_f} du F_m(alpha) tau^{-n_t-m},  F_m = sum_j num_j (-Phi)^{j+2-n_t-m}/(j+2-n_t-m)!
(t_sigma = eps v, t_f = eps u_f).  Feynman parameters for the ordinary edges u_f = U beta_f, U >= L(beta) = max_f c_f/beta_f;
the special time v and U in closed form,
  I_m(a,b;L) = int_0^1 dv int_L^oo dU v^a U^b (U+v)^{-(a+b+2+m)}  (U = v w, x = w/(1+w)): polynomial in y_L = L/(1+L)
  (times L^{-m}), plus -B(0) log y_L for m = 0;
the beta-simplex split by the edge attaining L, the other beta's integrated by the Dirichlet formula on the shifted
simplex, the last one-dimensional integral exact (w = c + s).  Values in Q + sum_p Q log p.  No log eps arises (bounded
tau range).  Checked against mpmath quadrature (n_t = 2, 3; rel. diff < 1e-12) and scrambled Sobol QMC (n_t = 4, 5,
cutoffs 1, 2; rel. diff ~ 1e-5).  log 5 appears in individual monomials for n_t = 5 or cutoff 2 and cancels in every
kernel used here.

6. FAMILIES (collinear on-shell outputs)
Engine components; n = (1,i,0,0), nbar = (1/2,-i/2,0,0) (twoletter choice), outputs p_j = t_j nbar (w = 0: on shell),
letter derivatives (n.d)^a via the null generating function (a! b! [ss^a su^b]), output (n.d)^c <-> (i t)^c.
Letters as charge eigenstates (ce_letters.py, Cartan rotations (45),(67),(89) R and (01),(23) Lorentz; spinor generator
from rho-equivariance): Z = A_4 + i A_5 (R (1,0,0)); psi = lambda_+ letter of R-weight (1/2,1/2,-1/2) and Lorentz weight
(1/2,1/2): Z, psi span the su(1|1) sector (Delta = J_1 + J_2 - J_3 in this labelling); its dual state u_psi is on shell
for p ~ nbar (checked: rho(nbar) u_psi = 0).  Gluon: eps = e_2 - i e_3 (n.eps = nbar.eps = 0), e' = e_2 + i e_3,
F11 := (1/2) c^{mn} F_{mn}, c = n ^ e' (Lorentz weight (1,1), the chirality of psi psi):
   F11 = (n.d)(e'.A) - (e'.d)(n.A) + [A_n, A_e'],  on shell F11 -> 2 i t (e'.eps = 2).
Covariant derivative D = d + [A,-] (A_n letter, n.A); (n.D)^a X = d^a X + sum_r C(a,r+1)[d^r A_n, d^{a-1-r} X] + ...
Planar reading (Lemma c10-colour (iv)): a kernel term c C_w on the adjacent pair (X_l X_{l+1}) -> (-1)^r (c/2)
Y_wr...Y_w1 (units u), odd outputs reordered from label order to trace order with the permutation sign, division by 2
for two outputs of the same field type (labelled form -> functional); graded cyclicity for words with fermions.
Projection to cohomology on the two-field part: evaluation on the collinear on-shell legs (s-exact terms vanish there,
descendants kept); for the gluon families the two-field images are decomposed on tr(d^c F11 d^d F11) values; terms with
an undifferentiated A_e' spectator or output (not of F-form) must cancel and do (gauge invariance check).
One-body terms (Lemma lem:cc-onebody): -{F'_Delta, X}^0 = u(c_phi - 2 theta_diamond w_X) X, c = 2/3 (A), 1/3 (lambda),
4/3 (c); position part -2 u theta_diamond d_b X.  kappa directions: -{u Q(kappa_V int(iota_x A_V,c*)), X} acts on A_V letters
only (A_p -> A_p + x^m d_p A_m type), -{u Q(kappa_lambda int(rho(x) lambda*,lambda*)), lambda} is proportional to
rho(x) dslash lambda: both are s-exact on cocycles (Prop prop:cc-arity1 (ii)) and vanish on the two-field shell; they
are kept as symbols in the formulas and drop from every on-shell matrix.
lc^natural = sum_pairs K^log - u sum_letters n_F (n_F = 2, 4 on A, lambda), K^log from tl_engine.Job in the same letters.
D_1 = 4 lc^natural + Xi_Delta, Xi_Delta = sum C^(2)_Delta - sum_a {F'_Delta, X_a}; reported translation-invariant
matrices with theta_perp, theta_lambda, theta_V symbolic; position part (D_1)^b = 2 sum C2_Pb - 2u sum theta d_b.
P_1 = sum C2_Pb - u sum_a theta^P_diamond d_b X_a (+ kappa^P, s-exact): on every family P_1 = -(1/3 + theta^P) u d_b on the
two-field shell for equal theta^P; covariant scheme theta^P = theta = -1/3: P_1 = 0.
