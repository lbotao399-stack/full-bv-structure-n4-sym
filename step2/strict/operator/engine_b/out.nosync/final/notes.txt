1. GENERATORS ON THE REGULATOR (ob_gen; Def op-gens, Def c7-vdot)
 v. = v^mu d_mu + (1/2) Om_{mn} Sigma^{mn} + (w/4) div v on every slot, Om_{mn} = (1/2)(d_m v_n - d_n v_m), Sigma^{mn} =
 (1/2) rho_m rho_n on spinors, (Sigma^{mn} A)_P = delta_{Pm} A_n - delta_{Pn} A_m on vectors; antifields of weight 4 - w.
 S^(1)(x) = int (x.A, A*) - (x.lam, lam*) - (x.c, c*), parity 1 (odd CE coordinate in front) for even x.
 Centred Killing data at the point x_O of the density (z = x - x_O):
   Delta:  2 z.d + 2 w            (orbital: z^mu x P-template at c = 2 e_mu; weight: spin-weight template, kap = 2)
   M_w:    (w z).d + spin, Om_{mn} = w_{nm}   (orbital: P-template at c_n = w_{n mu}; spin: SW template)
   R:      (1/2) R_{MN} Sigma^{MN}, M, N in 4..9 (SW template, W block)
   K_b:    v(z) = z^2 b - 2(b.z) z: z^mu z^nu x P-template at the coefficient vector; z^mu W_mu with
           Om^{(mu)}_{mn} = 2(delta_{m mu} b_n - b_m delta_{n mu}), kap = -2 b_mu (div v/4 = -2 b.z)
   xi:     T1+T2 = -(Gamma(xi,lam), A*), T3+T4 = (1/2)(rho(dA) xi, lam*), T5 cubic (qb_core)
   eta:    sum_mu z^mu S^(1)(rho(e_mu) eta) + s_0, s_0 = -(rho(A_perp) eta, lam*)
 Position factors: a momentum h is injected at the S vertex and absorbed by omega; z^mu -> -i d/dh_mu, z^mu z^nu ->
 -d^2/dh_mu dh_nu at h = 0.  The position parts (Thm op-b (i)) are the h^0 parts of the same rows:
 Upsilon_Delta = 2 x_O^mu Upsilon_{P_mu} + Upsilon^0_Delta, Upsilon_M = (w x_O)^mu Upsilon_{P_mu} + Upsilon^0_M,
 Upsilon_eta = x_O^mu Upsilon_{rho(e_mu) eta} + Upsilon^0_eta, Upsilon_K = v(x_O)^mu Upsilon_{P_mu} - (b.x_O) Upsilon^0_Delta
 + Upsilon^0_{M_{w_xO}} + Upsilon^0_K.  OP0 checks (exact, plane waves): [x.,Q] = 0 for every generator, [x.,Q^GF], [x.,H],
 the variation kernels (zero along P_b, M_w, R; -4(eps d_eps + T d_T) P along Delta) and the composite lines ([Q, P* x. P*]
 = 0 along Delta, P_b, M_w for any g(H); = [v.,P*]E - [v.,E]P* != 0 along K_b; P* R. P* = 0: no line along R); the
 opposite spin sign along M_w fails [v.,Q] = 0 (fixes Om_{mn} = w_{nm}).

2. THE DEFECT CYCLES (ob_job.OJob, mode 'defect'; conventions of qsk engine B, verified there by G-pole, G-reg)
 D_x(X_a,X_b) = +(hbar/2) sum_{ordered vertex sequences, S at position s} sum_sigma s_x(s,sigma) STr[E_0 Pi h_1 E_1 ... Pi h_n E_n Pi H_M],
 E_sigma = K_eps - K_0 = (e^{-eps k^2} - 1) k0 (Schwinger time in [0,eps], numerator -|k|^2), other E_j = P(eps,oo);
 s_x(s,sigma) = (-1)^{n(<sigma) + |S^(1)(x)| (n(<s) + [s<sigma])} x (reordering sign of the odd outputs), n(<j) = number
 of odd outputs before edge j (Def c11-defect (ii) without its leading minus; the overall sign is the calibrated route-B
 STr normalisation).  Placement classes: 'line' (both legs of S on edges P: the special-edge composite cycles, whose eps^0
 coefficient is C_x), 'special' (one leg on the special edge, including S on a letter), 'cubic-*' (T5).
 Arity-zero special-edge cycles (Upsilon_0): the same without S (mode 'defect', vertex None).  Counterterm cycles (ct_m,
 lc; arity one ct^(1)_{x,m}): all edges P, pinned-edge formula of the twoletter engine (mode 'ct'); OJob reproduces
 tl_engine.Job exactly (three leg sets, gate in PROGRESS).  Exact coefficients: Gaussian loop integral, Feynman
 parameters, special time in [0,1] (ce_int.J): values in Q(i) + Q(i) log 2 + Q(i) log 3; no log eps can arise.
 Rows with three or four outputs, and two-output rows whose symbolic polynomials exceed the memory cap, are evaluated at
 fixed Gaussian-integer output polarisations (and, as a last resort, letters) with deterministic seeds; the evaluation
 point is recorded in the row and in the table; all kinds of one leg set use the same point.

3. FINDING B-F1 (finite special vertex)
 Def op-defect (iii) adds to [eps^0] D_x the finite special vertex F_x = -sum_m ((-1)^m/m!)({I, ct^(1)_{x,m}}_{H^m} +
 {S^(1)(x), ct_m}_{H^m}).  The (Br) graphs whose special edge joins an output of the bare pair cycle to S^(1)(x) (or to a
 vertex of I) and the special part of the counterterm brackets sum to (e^{-eps H} - 1) x (renormalised cycle) -> 0, so the
 pieces cancel; the theory keeps one of them.  Computed: on (lamP,lamM) -> A_V (n = 0), [eps^0] D^special_Delta = 4 lc
 exactly and [eps^0] D_{P,M,R} = 0, so Upsilon = [eps^0] D obeys Conj op-pair and the second evaluation; Upsilon + F
 misses both by F_Delta = 6 H ct_1, F_P = H d_b ct_1.  The engine uses Upsilon_x = [eps^0] D_x; F_x is tabulated (key F).
 The pole identity in its reduced form, [eps^-m] D^0_Delta = -4m ct_m (scaling: {S(Delta), ct_m(O)} - ct_m({S(Delta),O})
 = 2(W - 2m) - 2W) and [eps^-m] D_{P,M,R} = 0 (covariance), holds on the rows where -ct^(1)_{x,m}(sO), s ct^(1)_{x,m}(O)
 and the vacuum-pole x spectator terms vanish (finding B-F3 lists the others).
