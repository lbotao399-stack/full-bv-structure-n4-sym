[S05] D. Stoeckinger, "Regularization by dimensional reduction: consistency, quantum action principle, and
      supersymmetry", JHEP 0503 (2005) 076, hep-ph/0503129 (read in full, text in src_pdf/stockinger2005/).
  - Sec 2: hierarchy QDS c Q4S, Q4S = QDS (+) QepsS; metrics g = ghat + gtilde, g.g = 4, ghat.ghat = D,
    gtilde.gtilde = eps := 4 - D (NB his eps = 4-D, not 2eps); ghat.gtilde = 0. Q4S infinite-dimensional
    ("index counting is not possible": five Q4S indices may all differ). Dirac algebra {g^mu,g^nu}=2g^{mu nu}
    in Q4S; Fierz identities NOT valid. Strictly 4-dim DRED inconsistent (Siegel PLB 94 (1980) 37):
    0 = D(D-1)(D-2)(D-3)(D-4) from eps-tensor + D-dim g.
  - gamma5 options: (i) anticommuting with all Q4S gammas (usual DRED) -> Tr(gamma5 x any gammas) = 0 for
    non-integer D (footnote 1: (4-D)Tr(g5 ghat^4)=0 etc.); (ii) gamma5bar = i g0g1g2g3 (HVBM-like) with extra
    projectors gbar (gbar.gbar=4) and g~~ (g~~.g~~ = 0): {g5bar, g^mu} = 2 g5bar g~~^mu ; with gamma5bar SUSY and
    gauge invariance broken already at one loop "like DREG" (eq. 4.5).
  - Charge conjugation C constructed in Q4S; usual flip relations (2.10)-(2.11) valid.
  - Sec 3: QAP holds in DRED; proof = BM proof; two ingredients: D_ij P_jk = i delta_ik at regularized level
    and vanishing of scaleless integrals.
  - Sec 4.2: S(Gamma_DRED) = i [S(Gamma_cl)] . Gamma_DRED (eq 4.3). With anticommuting gamma5, S(Gamma_cl) =
    int (Delta_gauge + Delta_fix + Delta_matter + Delta_pot + Delta_Yg + Delta_Yc + Delta_Ypsi), all
    four-fermion-type or Y-dependent, all vanishing in 4d by Fierz; Delta_fix = 0;
    Delta_gauge = (i/2) g f_abc (epsbar gamma^mu g_a)(gbar_b gamma_mu g_c).
  - Sec 4.3: topology rules (4.10): insertion vanishes if the gamma-string B of the closed fermion loop has
    <= 4 (topology a, gaugino loop), <= 2 (b), <= 3 (c) gammas. Results: propagator ST identity (4.6) and
    SUSY-transformation identity (4.7) valid to TWO loops in DRED; phi^4 identity (4.8) valid at ONE loop,
    possibly violated at two loops; at higher orders restoring counterterms "might be necessary".
  - App A: Q4S built as QDS (+) QepsS, each a Wilson/Collins formal space; gammas via block construction
    from DREG gammas; Tr defined with Tr 1 = 4.

[G17] C. Gnendiger, A. Signer, D. Stoeckinger et al., "To d, or not to d, that is the question", EPJC 77 (2017)
      471, arXiv:1705.01827, eq. (2.3): QS[ds] = QS[d] (+) QS[n_eps], S[4] c QS[d]; (3.1): QS[ds] =
      S[4] (+) QS[-2eps] (+) QS[n_eps]. For DRED/FDH ds = 4. => hierarchy 4S c QDS c Q4S used in bv_dr.tex.

[BIMS20] H. Belusca-Maito, A. Ilakovac, M. Madjor-Bozinovic, D. Stoeckinger, JHEP 08 (2020) 024,
      arXiv:2004.14398 (BMHV, chiral YM + scalars, one loop).
  - Sec 2: LIM_{d->4}: d->4 then evanescent objects -> 0, after reduction to a unique normal form
    (cyclic traces valid in BMHV).
  - Sec 3.3: s_d S_0 = s_d S_0,evan = Deltahat (3.39a); regularized ST identity S_d(S_0) = Deltahat (3.39b);
    for chiral fermions Deltahat = int (g T_R) c psibar (i dslash-hat P_R + ...) psi (3.40): evanescent.
  - (3.44)-(3.46): linearized ST operator b_d; NOT nilpotent (b_d^2 != 0) because S_0 is not invariant.
  - (4.4): counterterm structure S_sct,inv + S_sct,evan + S_fct,inv + S_fct,restore + S_fct,evan.
  - (6.3) S_d(Gamma_DReg^(1)) = S_d(Gamma^(1)) + b_d S_sct^(1) + b_d S_fct^(1); (6.5) regularized QAP
    S_d(Gamma^(1)) = Deltahat . Gamma^(1); (6.6) restoring condition
    0 = LIM( [Deltahat.Gamma^(1)]_div + b_d S_sct^(1) + [Deltahat.Gamma^(1)]_fin + b_d S_fct,restore^(1) ).
  - Sec 6.2 Bonneau identity (6.14): [N[Ohat].Gamma_Ren]^(1) = LIM( - r.s.p. [Ocheck . Gamma]^(1) )|_{gcheck=0},
    r.s.p. = residue of simple pole in nu = 4-d; Ocheck: evanescent metric ghat replaced by gcheck with
    gcheck^mu_mu = 1, gcheck.gbar = 0. Finite breaking = local, from UV poles only.

[MPW96] N. Maggiore, O. Piguet, S. Wolf, NPB 458 (1996) 403 [Err. 469 (1996) 513], hep-th/9507045.
  - (2.3): generalized BRST with constant ghosts eps (SUSY, commuting), xi^mu (translations, odd),
    eta (R): s cbar = b - i xi.d cbar, s b = -2i eps sigma^mu epsbar d_mu cbar - i xi.d b,
    s xi^mu = -2 eps sigma^mu epsbar.  => homotopy on the trivial pair (cbar,b) at quadratic order in
    the SUSY ghosts; with a xi_GF b^2 term this gives the arity-two cbar cbar vertex.
  - (2.8): S_gf = s int cbar d.A = int b d.A + dcbar (Dc + eps sigma lambdabar + lambda sigma epsbar):
    lambda-cbar vertex along SUSY (Landau gauge there).
  - (2.10): S_ext contains terms quadratic in external sources (lambda* lambda*, psi* psibar*) because s is
    nilpotent only on shell: the analogue of S^(2) in the HK project.
  - (2.12)-(2.15): SST identity S(Sigma) = 0, linearized B_Sigma nilpotent.

DECISIONS (2026-11-05, before writing bv_dr.tex)
 D1 dimension symbol: D (as in [S05]); never 'd' (HK uses d = exterior derivative) and never 'eps' (HK heat-kernel
    boundary). Expansion variable 4-D; Gamma((4-D)/2) ~ 2/(4-D).
 D2 spaces: [S05]/[G17] hierarchy 4S c QDS c Q4S, QDS = 4S (+) Q(D-4)S, Q4S = QDS (+) Q(4-D)S; restrictions
    written with HK's '|_' (A|_{QDS} etc.), no ghat/gbar symbols in formulas.
 D3 DRED scheme: V_10 -> Q4S (+) W_R^perp (formal "10"), fields depend on QDS coordinates; Clifford algebra
    abstract with totally anticommuting formal chirality (Sigma/Sigma^* kept), Gamma_11-odd traces = 0.
 D4 BMHV scheme: V_10 -> QDS (+) W_R^perp, 4d spinor structure explicit on 4S, evanescent Clifford factor
    formal; Majorana map J (SO(4)_R real structure on W) needed for the evanescent kinetic term; no-go:
    no BMHV kinetic operator on Pi Sigma (x) g alone preserves gauge invariance and SU(4)_R.
 D5 non-minimal pair (cbar, b), gauge fermion Psi = int (cbar, -d^*A|_QDS + xi_GF b); with HK's pairing
    normalisation xi_GF = 1 is Feynman gauge (gauge term -(hbar/2 xi_GF)(d.A^a)^2). Gauge parameter named
    xi_GF (HK ch08 uses xi for spinor parameters). Translation/special-conformal parameters written v_1
    (HK ch02 notation), because b is the Nakanishi-Lautrup field.
 D6 gauge-fixed equivariant action S_Psi := exp({Psi,-}) S_nm: MC preserved; Deltahat_Psi = exp({Psi,-})Deltahat;
    vertices {Psi, S^(1)(x)} (lambda-cbar along xi, eta; V-cbar along K with coefficient 2(D-2) of (cbar,iota_{v_1}A));
    arity-two cbar cbar vertex from the homotopy on the trivial pair, prop. to xi_GF.
 D7 Weyl weights in D dims: 4d geometric weights (A:1, lambda:3/2, c:0, cbar:2, b:2), antifields D-w.
    => Deltahat^(1)(v) = (4-D) int sigma_v L_0 for every even v (sigma = div v / D).
 D8 DR obstruction: Ob := LIM( Deltahat.Gamma^(1) - b_D I^CT,(1) ); one-loop finite parts of evanescent
    insertions = -2 d/dD of the normal-form residue polynomial at D=4 (Bonneau-type).
